# Security Policy

## Supported Versions

Security updates apply to the latest release version on `main`.

## Reporting a Vulnerability

If you discover a security vulnerability in Wide IDE (such as native-host privilege escalation, IPC boundary bypass, vault encryption weakness, or update verification bypass):

1. Open a private GitHub Security Advisory at https://github.com/sl4de0day/wide-ide/security/advisories/new.
2. Provide reproduction steps, operating system details, and a minimal proof of concept.
3. Wait for a patched release before public disclosure.
